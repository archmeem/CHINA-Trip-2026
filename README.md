# China Trip 2026 Booking Manager

Minimal mobile-first PWA for iPhone/desktop.

Features: full itinerary, booking-open dates, Book Today dashboard, status tracking, English + smaller Chinese names, editable booking details, ticket/PDF/screenshot upload stored locally in IndexedDB, ticket viewer, calendar view, and .ics reminder export.

## iPhone
For full PWA behavior, host these files on any HTTPS static host (GitHub Pages, Cloudflare Pages, Netlify, etc.). Open the HTTPS address in Safari and use Share → Add to Home Screen.

Opening index.html directly can show the UI but iOS does not provide full PWA/service-worker behavior from file://.

## Privacy
Booking details and uploaded files stay in that browser/device. This build has no server and no cloud sync.
